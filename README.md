# Microbial Fermentation Explorer

**Category:** Biology Simulation

Design and observe competing microbial ecosystems in real-time. Five species (Lactobacillus, Saccharomyces, E. coli, B. subtilis, Clostridium) compete for resources based on pH, temperature, oxygen, and sugar availability. Watch acidification cascades, symbiotic relationships, and population crashes emerge as metabolic byproducts reshape the environment.
